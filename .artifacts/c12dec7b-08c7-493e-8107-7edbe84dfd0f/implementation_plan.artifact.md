> [!WARNING]

## 1. UAT-007: Identity Uniqueness Strategy

### Data Audit Procedure
Administrators must execute the following SQL script to detect active duplicate identity numbers before applying the migration.

```sql
-- HASAD Identity Uniqueness Audit Script
-- Detects active farmers with duplicate Identity Numbers
WITH ActiveDuplicates AS (
    SELECT IdNumber
    FROM Farmers
    WHERE IsDeleted = 0
    GROUP BY IdNumber
    HAVING COUNT(*) > 1
)
SELECT
    f.IdNumber AS [Identity Number],
    f.Id AS [Farmer Id],
    f.FirstNameAr + ' ' + f.FamilyNameAr AS [Farmer Name],
    it.NameAr AS [Identity Type],
    g.NameAr AS [Governorate],
    dir.NameAr AS [Directorate]
FROM Farmers f
JOIN ActiveDuplicates ad ON f.IdNumber = ad.IdNumber
JOIN IdTypes it ON f.IdTypeId = it.Id
LEFT JOIN Governorates g ON f.GovernorateId = CAST(g.Id AS NVARCHAR(50))
LEFT JOIN Localities l ON f.LocalityId = CAST(l.Id AS NVARCHAR(50))
LEFT JOIN Directorates dir ON l.DirectorateId = dir.Id
WHERE f.IsDeleted = 0
ORDER BY f.IdNumber;
```

### Migration Plan
1. **EF Core**: Drop the composite index `IX_Farmers_IdTypeId_IdNumber`.
2. **EF Core**: Create a new unique filtered index `IX_Farmers_IdNumber` with filter `[IsDeleted] = 0`.
3. **Application**: Update `CreateFarmer` and `UpdateFarmer` command handlers to check only `IdNumber`.
4. **Mobile**: Update `OfflineFirstFarmerRepository` to check only `idNumber` during local validation.

## 2. UAT-004: Error Propagation Audit

### Root Cause Analysis
The generic message "An unexpected error occurred" is generated by global `catch (_)` blocks in Riverpod `StateNotifier`s. These blocks swallow the actual exception details.

### Resolution
- **Preserve Exceptions**: Replace `catch (_)` with `catch (e, st)` and propagate meaningful error messages.
- **ProblemDetails**: Ensure backend `ProblemDetails` (errors list) are correctly mapped to `FarmerException` / `FarmException`.
- **Database Errors**: Capture and display Drift/SQLite errors (e.g., uniqueness violations) with user-friendly descriptions.

### Reusable `FormSaveFooter`
Implement a project-wide standard component for all editable forms.

**Features:**

- **Validation-Driven UI**:
    - **Valid**: Primary theme color (Blue).
    - **Invalid**: Error color (Red).
- **Loading State**: Disables interaction and shows progress indicator.
- **Dynamic Binding**: Automatically listens to form field changes to update state live.
